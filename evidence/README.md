# Free-model evaluation evidence

- [Initial seven-case evaluation report](FREE-MODEL-EVALUATION-2026-11-08.md)
- [Reproduction harness](../scripts/free-model-evaluation.mjs)

The initial execution was performed on 2026-11-08 through a public anonymous inference endpoint with no API key or Authorization header. It used synthetic prompts and local synthetic tool functions. The route selected more than one model ID, so actual model identity is recorded per turn in the original Vercel sandbox execution log. The report summarizes verified outcomes; it is not a statistically valid benchmark.
