# Free-model evaluation evidence

- [Initial seven-case evaluation report](FREE-MODEL-EVALUATION-2026-11-08.md)
- [Reproduction harness](../scripts/free-model-evaluation.mjs)

The initial execution was performed on 2026-11-08 through a public anonymous inference endpoint with no API key or Authorization header. It used synthetic prompts and local synthetic tool functions. The route selected more than one model ID, so model identity is recorded per turn. Raw request IDs and traces were preserved in the Vercel sandbox during execution; the report summarizes the verified outcomes. This is not a statistically valid benchmark.
